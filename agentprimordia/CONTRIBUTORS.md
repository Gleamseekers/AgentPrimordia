## 如何成为贡献者

我们欢迎各种形式的贡献！请查看 [CONTRIBUTING.md](./CONTRIBUTING.md) 了解更多信息。

### 贡献类型

- 🐛 **Bug 修复** - 修复代码中的问题
- ✨ **新功能** - 添加新的功能特性
- 📝 **文档** - 改进或添加文档
- 🎨 **设计** - 改进 UI/UX 设计
- 🧪 **测试** - 添加或改进测试
- 🌍 **翻译** - 将文档翻译成其他语言
- 💡 **想法** - 提供改进建议

## 贡献者指南

### 第一次贡献？

如果你第一次参与开源项目，可以按照以下步骤：

1. 查看标记为 `good first issue` 的 Issue
2. Fork 项目到你的 GitHub 账户
3. 创建一个新分支：`git checkout -b my-first-contribution`
4. 做出你的更改
5. 提交并推送：`git push origin my-first-contribution`
6. 创建 Pull Request

### 需要帮助？

- 查看 [贡献指南](./CONTRIBUTING.md)
- 在 [Discussions](https://github.com/Gleamseekers/AgentPrimordia/discussions) 中提问
- 加入我们的 Discord 社区
