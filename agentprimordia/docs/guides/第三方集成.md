# 第三方接入指南（30 分钟接入真实场景）

> v4.4-5 开发者平台：从「框架可嵌入」到「第三方可低成本接入」。
> 目标：按本文档在 30 分钟内把 AgentPrimordia 接入真实业务场景。

## 接入全景

```
第三方系统
  │  A2A 双向（委托任务/被委托）
  ├── 作为调用方：ap A2A 客户端 → 远程 Agent（跨生态委托）
  ├── 作为服务方：ap A2A 服务端 ← 生态客户端（开放协议）
  │
  │  双 SDK 快速上手
  ├── Go：go get github.com/Gleamseekers/AgentPrimordia/v7/agentprimordia/pkg
  └── TS：npm install @agentprimordia/sdk
```

## 一、双 SDK 快速上手（5 分钟）

### Go（推荐后端服务）

```go
package main

import (
	"context"
	"fmt"

	ap "github.com/Gleamseekers/AgentPrimordia/v7/agentprimordia/pkg"
)

func main() {
	ctx := context.Background()

	// 1. Provider（本地 Ollama 免 key，或 OpenAI/Anthropic/Gemini）
	provider, _ := ap.NewOllamaProvider(ap.Config{Model: "qwen3:8b"})

	// 2. 创建 Agent（ReAct 循环 + 工具 + 护栏）
	agent, err := ap.NewAgent("my-agent", "你是客服助手。", provider,
		ap.WithMaxTurns(8),
		ap.WithToolkit(ap.NewToolRegistry()),
	)
	if err != nil {
		panic(err)
	}

	// 3. 运行
	resp, err := agent.Run(ctx, ap.UserMessage("查询订单 1001 状态"))
	fmt.Println(resp.Content)
}
```

### TypeScript（推荐前端/边缘）

```ts
import { Agent, OpenAIProvider } from '@agentprimordia/sdk';

const provider = new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY!, model: 'gpt-4o-mini' });
const agent = new Agent({
  name: 'my-agent',
  systemPrompt: '你是客服助手。',
  provider,
  maxTurns: 8,
});

const resp = await agent.run('查询订单 1001 状态');
console.log(resp.content);
```

## 二、A2A 双向接入（15 分钟）

两套客户端不要混用：**ap 集群内**走 gRPC（`NewA2AGRPCServer` / `NewA2AGRPCClient`）；
**跨生态**走开放协议（`NewOpenInteropServer` / `NewOpenInteropClient`，JSON-RPC over
HTTP + SSE）。完整对照见 [`A2A互通.md`](A2A互通.md)。

### 作为服务方：开放你的 Agent

```go
// 1. 部署 A2A 服务端（gRPC 传输，ap 内网）
card := ap.NewA2AAgentCard("my-agent", "客服助手")
svc := ap.NewA2AService(card, ap.NewA2ATaskManager())
grpcServer := ap.NewA2AGRPCServerWithService(svc) // 内部完成 Register，可直接 Serve

// 2. 启动监听
lis, err := net.Listen("tcp", ":50051")
if err != nil {
    log.Fatalf("监听失败: %v", err)
}
if err := grpcServer.Serve(lis); err != nil {
    log.Fatalf("服务失败: %v", err)
}

// 若要同时对外提供开放协议互操作面（HTTP/SSE），另起一个：
//   interop := ap.NewOpenInteropServer(openCard, ap.DefaultInteropConfig())
//   http.ListenAndServe(":8080", interop.Handler())
```

### 作为调用方：委托远程 Agent

```go
client, err := ap.NewA2AGRPCClient("remote-host:50051") // 双返回值：client + error
if err != nil {
    log.Fatalf("连接失败: %v", err)
}
defer client.Close()

// 方法集：FetchAgentCard / CreateTask / GetTask / CancelTask / StreamEvents / Close
// CreateTask(ctx, *A2AMessage, taskID) —— 没有 SendTask，消息也不是裸字符串
task, err := client.CreateTask(ctx, &ap.A2AMessage{
    Role:  "user",
    Parts: []ap.A2APart{ap.NewA2ATextPart("请汇总本月销售数据")},
}, "")
if err != nil {
    log.Fatalf("创建任务失败: %v", err)
}

// 轮询：GetTask 失败返回 (nil, err)，禁止 _ 丢弃后解构
for {
    got, err := client.GetTask(ctx, task.ID)
    if err != nil {
        log.Fatalf("查询失败: %v", err)
    }
    fmt.Printf("任务状态: %s\n", got.State)
    if got.State == "completed" || got.State == "failed" { // A2ATaskState 字面量
        break
    }
    time.Sleep(200 * time.Millisecond)
}

// 拉取产物
for _, artifact := range task.Artifacts {
    _ = artifact
}

// 或订阅流式事件（无需轮询）
events, err := client.StreamEvents(ctx, task.ID)
if err != nil {
    log.Fatalf("订阅失败: %v", err)
}
for ev := range events {
    fmt.Printf("事件: %s\n", ev.Type)
}
```

### TS 侧对等实现

```ts
import { OpenInteropClient, newTextMessage, isTerminalState } from '@agentprimordia/sdk';

// 开放协议互操作客户端（与 Go 的 ap.NewOpenInteropClient 对等）
const client = new OpenInteropClient('https://agent.example.com');

const card = await client.fetchAgentCard();                       // 发现
const task = await client.sendTask(newTextMessage('user', '请汇总本月销售数据')); // 委托

let current = task;
while (!isTerminalState(current.status.state)) {                  // 轮询
  await new Promise((r) => setTimeout(r, 200));
  current = await client.getTask(task.id);
}
await client.cancelTask(task.id);                                 // 取消
```

> TS 侧另有 `A2AClient`（`sdk/typescript/src/a2a/transport.ts`），构造为
> `new A2AClient(transport, agentID)`、方法为 `sendMessage(target, content)`，属 ap 集群内
> 传输对等物，不要与上面的开放协议客户端混用。

## 三、接入真实场景清单（30 分钟）

| 分钟 | 步骤 | 验证 |
|------|------|------|
| 0-5 | 双 SDK 快速上手（上文一） | `go run .` / `npm run dev` 输出应答 |
| 5-15 | 接真实 LLM：设 `AP_LLM_PROVIDER/AP_LLM_MODEL/AP_LLM_API_KEY` 或本地 Ollama | 用真实模型回答 |
| 15-25 | 挂业务工具：filesystem/shell/自定义 `ap.Tool` | 工具调用日志可见 |
| 25-30 | A2A 双向（上文二）：开放服务 + 远程委托 | 跨服务任务完成 |

## 四、常见问题

- **工具权限**：默认受限工作区，用 `ap.WithFilesScope("/data")` 扩展
- **成本控制**：`ap.WithCostTracker` 预算拦截；Pool 租户配额
- **观测**：`ap.WithTelemetry` 接入 OTel；`/api/failures` 一键重放失败
- **安全**：guardrail 输入/输出端默认开启；插件安装强制验签（ECDSA P-256）
