# 真实外部环境验收手册（Verification Runbook）

> 本文档固化 v4.1–v5.0 弧线中依赖外部环境的验收项的操作步骤。
> 所有"就绪但未真实运行"的验收在此按步骤执行即可判定通过。

## 前置：环境与密钥

| 依赖 | 获取方式 | 环境变量 |
|------|---------|---------|
| OpenAI API Key | platform.openai.com | `OPENAI_API_KEY` 或 `AP_LLM_API_KEY` |
| 本地 LLM（免 key 替代） | `ollama pull qwen3:0.6b` | `AP_LLM_PROVIDER=ollama AP_LLM_MODEL=qwen3:0.6b` |
| faster-whisper（ASR） | `docker run -d -p 9000:9000 fedirz/faster-whisper-server:latest` | `AP_ASR_URL` |
| Piper（TTS） | `python -m piper.http_server --model en_US-lessac-medium --port 5002` | `AP_TTS_URL` |
| GPU 浏览器 | Chrome/Edge + WebGPU | — |

## 1. 真实 LLM 跑分（v4.1 基线 / v4.2 双线 / v4.9 成本）

```bash
cd agentprimordia
export OPENAI_API_KEY=sk-...

# 编码跑分（60 条真实任务，门禁：≥基线，分数只升不降）
go run ./bench/llm-bench --provider openai --model gpt-4o-mini --version v7.3.0 --out bench/results/2026-Q4-coding.json

# autonomy / skills 能力跑分（替换 0 分基线文件）
go run ./bench/llm-bench --ability autonomy --provider openai --model gpt-4o-mini --out bench/results/2026-Q3-v4.1-autonomy-baseline.json
go run ./bench/llm-bench --ability skills --provider openai --model gpt-4o-mini --out bench/results/2026-Q3-v4.1-skills-baseline.json

# TS 侧（双线对照）
cd ../sdk/typescript && npx --yes tsx bench/llm-bench/main.mts --model gpt-4o-mini --out ../agentprimordia/ts-report.json
cd ../agentprimordia && node ../scripts/dual-bench-compare.mjs --go-report ... --ts-report ts-report.json --out bench/results/dual
```

**判定**：三个报告 pass_rate 替换 0 分基线并写入 ROADMAP 状态行；对照表用例集一致、分歧数记录。CI 等价入口：nightly `llm-benchmark` / `ts-llm-benchmark` / `dual-bench` job（配 Secrets 自动跑）。

## 2. 真实语音会话（v4.1/v4.3 验收：本地免 key 必达）

```bash
# 路径 A：本地免 key（必达项）
docker run -d -p 9000:9000 fedirz/faster-whisper-server:latest
python -m piper.http_server --model en_US-lessac-medium --port 5002
./scripts/dev-realtime.sh --asr-url http://127.0.0.1:9000/v1/audio/transcriptions \
  --tts-url http://127.0.0.1:5002/v1/audio/speech

# 路径 B：OpenAI 端点
AP_LLM_PROVIDER=openai AP_LLM_API_KEY=sk-... go run ./ecosystem/examples/realtime-voice/
```

**判定**：demo 输出含真实转写与合成音频（非 mock 前缀）；多轮 + 打断演示通过；流式链路由 `TestRuntime_ProcessTurnStream` 覆盖（mock，链路级验证）。
