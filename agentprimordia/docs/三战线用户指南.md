## 零门槛入口

### 5 分钟启动你的第一个 Agent

**无需 API key，无需复杂配置，一条命令即可开始。**

```bash
# 安装 ap 命令
cd agentprimordia
go build -o /usr/local/bin/ap ./cmd/ap

# 创建并启动 agent
ap start my-first-agent
```

**你会看到：**
```
创建项目 "my-first-agent" ...
✓ 项目已创建 (Templates: quickstart)
✓ 依赖安装完成

未检测到 API key，将使用 Demo 模式
提示: 设置 AP_LLM_API_KEY 启用真实 LLM

编译 my-first-agent-agent ...
✓ 编译完成

AgentPrimordia 快速入门
=========================
Agent已创建
   名称: QuickStartAgent

开始对话...
```

### Demo 模式

没有 API key？没关系！Demo 模式基于关键词匹配提供有意义的响应，让你立即体验 agent 的基本功能。

**Demo 模式支持的场景：**
- 问候和自我介绍
- 代码审查请求
- 帮助和支持
- 任务管理
- 配置查询

**切换到真实 LLM：**
```bash
# 设置 API key
export AP_LLM_API_KEY=sk-your-key-here

# 或者使用 ap config 命令
ap config set api-key sk-your-key-here
ap config set provider openai
ap config set model gpt-4o
```

## 学习闭环体感

### 越用越强的秘密

AgentPrimordia 的核心差异化：**让 agent 的学习过程可见、可量化、可追溯。**

**学习机制：**
1. **SelfModel** — 记录每个能力域的成功率、趋势
2. **GrowthEventLog** — 记录关键里程碑事件
3. **ToolLearner** — 记录工具使用效果
4. **Consolidator** — 蒸馏经验为语义记忆

### 查看成长报告

```bash
# 查看总体表现
ap profile

# 输出示例：

Weak Areas:
  1. sql-query          45% (5/11)   declining ↓

Memory: 234 episodic / 18 semantic / 42 forgotten
Tool Learning: best filesystem.read(98%), worst shell.exec(67%)

Recent Growth Events:
  [09-08 15:30] code-review-go unlocked (success > 70%)
  [09-08 15:28] 10th semantic experience distilled
  [09-08 15:25] code-review-go mastered (success > 90%)
```

### Studio 可视化面板

```bash
# 启动 Studio
ap studio

# 浏览器打开 http://localhost:8080
```

**Studio 功能：**
- **能力雷达图** — 直观展示各领域能力分布
- **成长曲线** — 成功率随时间变化趋势
- **工具热力图** — 哪些工具用得多、效果好
- **记忆统计** — 情景记忆、语义记忆、遗忘曲线
- **成长事件时间线** — 关键里程碑记录

### 学习数据流

```
用户对话
  ↓
Agent 执行任务
  ↓
SelfModel.RecordOutcome(domain, success, turns)
  ↓
检测里程碑（能力解锁、精通等）
  ↓
GrowthEventLog.Record(event)
  ↓
Studio 实时展示
```

## 生态协议互联

### A2A 协议

AgentPrimordia 实现了完整的 Agent-to-Agent (A2A) 协议，让多个 agent 可以发现彼此、分配任务、协同工作。

**核心能力：**
- **Agent Card 发现** — `/.well-known/agent.json`
- **任务管理** — 创建、查询、取消任务
- **SSE 流式推送** — 实时任务状态更新
- **gRPC 双传输** — HTTP/JSON-RPC + gRPC

### 两个 Agent 通信示例

```bash
# 终端 1：启动数学 agent
ap start math-agent --template with-tools

# 终端 2：启动编排 agent
ap start orchestrator-agent

# 在 orchestrator-agent 中
> 计算 2 + 3 * 4

[Orchestrator] 发现 math-agent @ http://localhost:9100
[Orchestrator] 发送任务到 math-agent...
[Math Agent] 接收任务，执行计算...
[Math Agent] 返回结果: 14
[Orchestrator] 收到结果，整理响应...

计算结果：14
```

## 常见问题

### Q: 没有 API key 能用吗？

**A:** 可以！Demo 模式提供基础功能体验。设置 API key 后自动切换到真实 LLM。

```bash
# 设置 API key
export AP_LLM_API_KEY=sk-your-key-here
```

### Q: 学习数据存在哪里？

**A:** 默认存储在项目的 `data/memory.db` SQLite 数据库中。可以导出查看：

```bash
ap profile export > profile.json
```

### Q: 如何查看 agent 的成长历史？

**A:** 使用 `ap profile` 命令：

```bash
# 查看总体报告
ap profile

# 查看成长事件历史
ap profile history

# 导出原始数据
ap profile export > profile.json
```

### Q: 多个 agent 如何通信？

**A:** 通过 A2A 协议。每个 agent 暴露 Agent Card，其他 agent 可以发现并调用。

```bash
# 启动 agent A
ap start agent-a

# 启动 agent B
ap start agent-b

# agent B 可以发现并调用 agent A
```

### Q: 如何接入国内 LLM（通义千问、智谱等）？

**A:** 支持多种国内 LLM：

```go
// 通义千问
provider := ap.NewQwenProvider(apiKey, "qwen-max")

// 智谱 GLM
provider := ap.NewGLMProvider(apiKey, "glm-4")

// 使用 ap config 配置
ap config set provider qwen
ap config set model qwen-max
```

### Q: 性能如何？

**A:** Go 的性能优势：
- **启动时间** < 5 秒
- **内存占用** < 50MB（空 agent）
- **零 GC 停顿**（单二进制部署）
- **原生并发**（goroutine + channel）

### Q: 如何部署到生产环境？

**A:** 编译为单二进制：

```bash
# 编译
go build -o my-agent ./my-agent

# 部署（只需一个文件）
scp my-agent server:/opt/
ssh server '/opt/my-agent'
```
