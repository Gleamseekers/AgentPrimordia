# AgentPrimordia 用户反馈收集计划

> 目标：收集 5-10 个早期用户的深度反馈，迭代产品体验

---

## 一、目标用户画像

### 理想用户特征

1. **Go 开发者** — 熟悉 Go 语言，有实际项目经验
2. **AI/Agent 兴趣** — 对 AI Agent 技术感兴趣，有探索意愿
3. **早期采用者** — 愿意尝试新工具，提供建设性反馈
4. **影响力** — 在 Go 社区或 AI 社区有一定影响力（可选）

### 用户来源渠道

1. **Go 社区** — Go 语言中文网、Go 夜读、GopherChina
2. **AI Agent 社区** — LangChain 社区、AI Agent Discord
3. **GitHub** — 已 star/fork 的用户
4. **技术会议** — Go meetup、AI 沙龙参与者
5. **个人网络** — 同事、朋友、前同事

3. 在 Go 社区论坛发帖招募
4. 在 AI Agent Discord 发布招募信息


## 三、试用指南

### 试用前准备

**发送给用户的文档：**
1. **快速开始指南** — 安装、运行、基本使用
2. **功能演示清单** — 要体验的核心功能
3. **反馈问题列表** — 引导用户关注的关键点
4. **问题反馈渠道** — GitHub Issues、邮箱、微信

### 试用流程（30-60 分钟）

**步骤 1：安装（5 分钟）**
```bash
# 安装 ap 命令
go install agentprimordia/cmd/ap@latest

# 验证安装
ap --help
```

**步骤 2：创建 agent（5 分钟）**
```bash
# 创建并启动 agent
ap start my-first-agent

# 观察输出，记录启动时间
```

**步骤 3：对话体验（15 分钟）**
```
# 进行 5-10 轮对话
> 你好
> 帮我审查这段代码...
> 分析这个数据...
> 谢谢
```

**步骤 4：查看成长报告（5 分钟）**
```bash
# 查看成长报告
ap profile

# 记录你的感受
```

**步骤 5：Studio 面板（10 分钟）**
```bash
# 启动 Studio
ap studio

# 浏览器打开 http://localhost:8080/dashboard/learning
# 探索雷达图、成长曲线、能力列表
```

**步骤 6：（可选）A2A 互联（10 分钟）**
```bash
# 运行 A2A 示例
go run ./ecosystem/examples/a2a-connect/
```

## 五、反馈分析与迭代

### 反馈分类

**按类型分类：**
1. **Bug 报告** — 功能异常、崩溃、错误
2. **体验问题** — 难用、困惑、不直观
3. **功能请求** — 希望增加的功能
4. **性能问题** — 慢、占用资源多
5. **文档问题** — 不清楚、缺失、错误
6. **正面反馈** — 满意、喜欢、推荐

**按优先级分类：**
1. **P0（紧急）** — 阻塞性问题，影响核心功能
2. **P1（高）** — 严重影响体验，需要尽快修复
3. **P2（中）** — 影响体验，可以在下个版本修复
4. **P3（低）** — 小问题，可以延后处理

- 平均满意度评分：≥ 7/10

## 九、风险与应对

### 风险 1：招募困难
**应对：**
- 扩大招募渠道
- 提高激励力度
- 降低试用门槛

### 风险 2：反馈质量低
**应对：**
- 提供更详细的引导问题
- 进行一对一访谈
- 跟进追问

### 风险 3：用户流失
**应对：**
- 定期跟进
- 快速响应问题
- 持续提供价值

### 风险 4：负面反馈
**应对：**
- 积极倾听，不辩解
- 承认问题，承诺改进
- 快速行动，展示进展
