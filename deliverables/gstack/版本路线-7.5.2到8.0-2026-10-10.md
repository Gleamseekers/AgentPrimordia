**日期**：2026-10-10（v2 修订同日）；实施进度更新至 2026-10-12（见 §八）

## 〇、先定规矩（版本纪律，建议并入 `docs/版本规范.md`）

1. **无主题不发版**：每一版一个用户可见主题 + 一份"不做清单"；主题说不清就不发。不可见重构（如 llm 收敛）不占主题，完成即合入、随下一版发布。
2. **API 冻结期（7.6–7.8，短冻结）**：`pkg/` 新增导出需维护者批准，CI 黄金快照把关。**冻结保的是承诺面，不是代码存在**——实现可动、可搬 internal/，公共契约不动。依据：eino 在 v0.9 仍逐小版本 breaking（[v0.8 breaking changes](https://www.cloudwego.io/docs/eino/release_notes_and_migration/v0.8._-adk_middlewares/eino_v0.8_breaking_changes/) 有专门迁移页），零用户期的 semver 纪律是税不是德——所以冻结要短要轻，破坏要趁早。
3. **8.0 的门是外部证据**：第一个外部用户干净环境 15 分钟首胜（有据可查），不是内部 checklist。
4. **研究阻塞的能力不进发布承诺**：任何"接口在、管线在、但关键环节无生产实现"的能力（当前：agent 自写工具链的 WASM 生成），可在文档标注研究状态，不得进入发布叙事与 quickstart。
5. **发布机制沿用**：bump `pkg/agent.go` 的 `const Version` → 自动 tag → §6.4 冒烟 11 项。

## 三、逐版方案

### v7.6 —「第一印象」（10-19 ~ 11-13）

**为什么是它**：成功定义是采用侧，而前门现在会把每个照着做的人第一步绊倒。实证断点：

| # | 断点 | 证据 |
|---|---|---|
| 1 | README 快速开始第一条命令 `go get agentprimordia` 直接失败 | `agentprimordia/README.md:73`；正确路径就在同页 import 里 |
| 2 | 版本徽章停在 v7.3.0（实际 7.5.1），头条能力表还是 v3.3–v3.6 时代 | README:6 |
| 3 | "5 分钟体验"要求 clone 仓库 + 仓库内 `./ap`；11 天前刚修好的 `go install` 只字未提 | README 方式 1 |
| 4 | `ap init` standalone 生成的 go.mod require 占位 v7.0.0——外部用户 tidy 完拿到旧版 | `cmd/ap/scaffold.go:136` |
| 5 | init 提示文案引用错误模块路径（无 `/v7`） | `cmd/ap/init.go:246` |
| 6 | quickstart 从未在干净环境验证过——没有机制保证，靠人记 | 10-10 路线图 DX Review 自认 🔴 |

**入范围**：
1. README 重写：第一屏 `go install .../cmd/ap@latest` + import 片段；删 `go get agentprimordia`；徽章版本删或 CI 注入；头条能力表更新为 v7.x 实况；"5 分钟体验"改为任意目录 `ap init` + demo 模式（免 API key 路径已存在）。
2. 英文前门：`README.md` 英文化（中文全量移 `README.zh-CN.md`）；`docs/getting-started/{五分钟入门,安装指南,第一个Agent}.md` 英译并校正。
3. 脚手架修复：standalone go.mod 占位版本由发布流水线注入当前 tag（或 init 后自动 `go get <module>@latest`）；`init.go:246` 文案路径修正；两者配单测。
4. **CI clean-room 门**（`.github/workflows/quickstart-smoke.yml`）：fresh container → `go install` → 仓库**外**目录 `ap init` → `go mod tidy` → build → demo 模式运行 → 断言输出关键字。PR 级用本地构建的 ap，发布后对真实 tag 复跑。**断点 6 的制度性修复。**
5. **API 冻结机制**：`pkg/api_surface_test.go` 黄金快照（`go doc -all ./pkg` 导出符号入 golden）；CI 检出新增导出即红，需维护者批准记录方可更新 golden。**必须在本版落地**——7.7 的 demo 会带来第一批用户，冻结要赶在他们之前。
6. 顺手项（不进叙事）：EnhancedPlanner 护栏（turns ≤20%、深度 ≤2）+ `pkg/planning.go` 注释补 `-47.8pp, p=0.001` 锚点（10-10 路线图 D6）。

**明确不做**：英文全量文档（留 7.8 最低集之外）；任何新功能；任何 pkg 新增导出。
**机器门**：clean-room job 绿；`doc-version-consistency.mjs` exit 0；README 前 3 条命令被 clean-room 逐字执行；api_surface 黄金测试绿；5298 测试不回归。
**退出判据**：1 名非维护者（或维护者以新人模式在干净 VM）按英文 README 15 分钟内跑到第一个 agent，记录在案。
**前置**：v7.5.2 已发（`go install` 通道稳定）。

### v7.7 —「楔子：A2A 多代理互操作」（11-16 ~ 12-11）

**为什么是它**：成功定义 (a) 下，采用取决于一个具体场景里 AP 明显最强。三条护城河逐一核查后：

| 候选 | 今天可 demo | 差异化真实性 | 处置 |
|---|---|---|---|
| 沙盒代码执行 | ❌ **生成器无生产实现**（`Generator`/`ToolCreator` 的全部"实现"在 `*_test.go`；`tool_forge.go` 注释自认"生成质量（WASM 化）属研究面"） | 窄：eino 有云端沙箱（Ark Agentkit），AP 是本地零依赖 + 验签 + CI 确定性断言 | **降为副线**（见下） |
| **A2A 多代理互操作** | ✅ `ap a2a interop-check` 在役、`ecosystem/examples/a2a-{interop,connect}` 已有雏形、cluster/gRPC + etcd/redis 检查点后端齐备 | 真实协议风口（A2A 已是跨生态开放协议）；Go 生态无第二家实现 + 符合性报告 | **主楔子** |
| 可复现评测文化 | 长线内容 | "唯一发表阴性结果的框架"是品牌不是功能 | 持续内容线，不占版本 |

**主线（A2A）入范围**：
1. 端到端 demo：两个 `ap` 进程（其一可跨主机）经 A2A 完成任务委托 → 中断 → 检查点恢复 → 结果回传；一条命令或一个脚本跑完，进 quickstart 与 cookbook（英）。
2. `ap a2a interop-check` 符合性报告随版发布（对外可引用的协议一致性证据）。
3. 英文概念页 `docs/concepts/multi-agent-interop.md`：协议定位、与 A2A 生态的关系、何时该用 / 不该用。
4. demo 进 clean-room 门（复用 7.6 job 机制，加 A2A 场景用例）。

**副线（沙盒安全叙事，主线完成才启动；上限 1 周）**：
- 手动供应链 demo：开发者自备 WASM 工具 → ed25519 签名 + 公钥钉扎 → 注册 → agent 沙箱调用；英文 `docs/concepts/security-model.md`（INV-0 / A1–A8 的可验证承诺）。此为 `pkg/wasm.go` 提供第一个真实消费者——仍无消费者则 8.0 删除（见 §四）。

**明确不做**：
- **"agent 自写工具"任何形式的承诺**（生成器是研究洞，V7 弧线整体阴性——10-10 路线图"不做清单"第 4 条同向）；
- 第二个对外主题；新认知实验；worldmodel 任何默认化。

**机器门**：A2A demo 在 clean-room <15 分钟完成；`ap a2a interop-check` 报告随版产出；A1–A8 + 红队 0 失败（副线若启动，红队加签名绕过 / 沙箱逃逸两辑）。
**退出判据（双轨）**：机器轨 = demo 门绿；采用轨 = 发布后 6 周内 ≥3 个外部尝试（issue / discussion / fork 有据），不足则触发 kill-switch 评审（§五）。
**前置**：7.6 的 clean-room 与 API 冻结在役。

### v7.8 —「8.0 彩排」（12-14 ~ 01-29）

**主题**：不为功能，为 8.0 扫清道路——每一处计划中的破坏都先打 deprecation 标记，迁移成本压到近零。

**入范围**：
1. **8.0 范围决定稿**（维护者逐项签署，§四表格）。
2. Deprecation 落地：所有 8.0 计划移除的导出加 `// Deprecated: ... 将于 v8.0 移除，原因 + 替代`；文档权威索引同步；grep 断言测试保证"决定稿里有的、代码里都有标记"。
3. `ap migrate` 工具：import 路径 `/v7` → `/v8` 机械重写（`gofmt -r` 规则集）+ `--check` 报告模式（供 CI）；在三个下游形态验证：`ecosystem/examples`、`operator`、`sdk/`（含 TS/Python/Rust 客户端与 gateway 模块的路径引用）。
4. 英文文档最低集：README + Quickstart + 3 概念页（框架定位 / 安全模型 / 多代理互操作）——8.0 采用的门，不能等 8.0 之后。
5. soak 决策落地：重启 harness 或正式改"暂停"，状态与 `soak-report.json` 一致，不再悬置。
6. Dependabot / Renovate 接入，109 处 SHA pin 自动保鲜。
7. 首批外部用户记录制度化：`ADOPTERS.md`（哪怕 1 个真实用户 + 场景）+ issue triage SLA 公示。

**明确不做**：提前执行删除（破坏全部留 8.0）；新功能。
**机器门**：8.0 移除项 100% 有 deprecation 标记（grep 断言）；`ap migrate --check` 三形态全绿；英文 clean-room 15 分钟首胜复跑绿；soak 状态与 report 一致。
**退出判据**：维护者签署 8.0 范围书；`ADOPTERS.md` 非空。
**前置**：7.6 API 黄金快照在役（diff 即 8.0 范围的事实来源）。

### v8.0 —「节食」（02-22 ~ 03-19）

**叙事**：**"我们砍掉了什么"**，不是"我们增加了什么"。287K 行 / 29 包的框架，8.0 的意义是把承诺面砍到与证据相称。

**主战场是 `pkg/` 公共 API 面，不是代码存在**：被移出的实现保留在 `internal/` 继续供 `cmd/ap` 使用——砍的是兼容性承诺、文档面、跨 5 端 SDK 的同步面。删除只留给被证据判死的。诚实声明：**LOC 不会显著下降**，8.0 买不到"框架变小"，买到的是定位清晰 + 破坏集中一次 + 维护面（承诺/文档/SDK 同步）约减半。

**入范围**：
1. `/v8` 模块路径（SIV 硬要求；零外部用户期是历史上最便宜的破坏时点——eino 在 v0.9 仍逐版 breaking 且活得更好，每多一个 AP 用户贵一分）。
2. 按 §四 签字表执行删除 / 移出。
3. llm BaseProvider 成果随常驻任务平移（无新工作）。
4. 迁移：`ap migrate` + 30 分钟迁移指南；`go.work` replace 兜底供 ecosystem 过渡。
5. 五端版本（Go / TS / Python / Rust / Operator）四方一致 + npm v8 + cosign + §6.4 冒烟 11 项。

**明确不做**：借 8.0 加任何新能力；保留任何"预留 API"；把研究阻塞能力（agent 自写工具）写进任何发布说明。
**GA 门（缺一不发）**：见 §五。
**前置**：7.8 退出判据全绿。

## 五、GA 门与 Kill-switch

**v8.0 GA 门（7 项，缺一不发）**：
1. clean-room 英文 README + A2A quickstart 15 分钟首胜（`/v8` import 路径）——主门；
2. A1–A8 + 红队双 0（0 容忍不变式随 `/v8` 迁移，不许以"重构"名义弱化）；
3. 测试数 ≥ 7.8 水平，剩余面覆盖率 ≥ 85%；
4. `ap migrate --check` 对 ecosystem/examples + operator + sdk 三形态全绿；
5. 五端版本四方一致 + §6.4 冒烟 11 项 + npm / cosign 全就绪；
6. `ADOPTERS.md` ≥ 1 个真实外部用户；
7. 每个移除项在 release notes 有证据锚点（阴性实验 / 0 消费者 / 维护成本）。

**Kill-switch（两道）**：
- **7.7 后 6 周**：A2A 楔子零外部尝试 → 暂停 7.8/8.0，开楔子复审（换沙盒安全叙事？换场景？还是承认 (a) 不可达转 (b)）。版本号不高于证据。
