# AgentPrimordia v7.0 路线图实施计划（v6.1 – v7.0）· 定稿

> **文档定位**：v6.0 大成收官（加权复测 ≈9.0/10，v6.0.0 于 2026-08-21 发布）后，v6.1–v7.0 的核心能力跃迁弧线。
>
> **修订说明**：
> - **初版（08-31a）**：评测真实化/语义原生/验证器/长程/跨节点/GA 六版——被维护者否决：全是补债与增强，违反铁律 2，撑不起主版本。
> - **修订稿（08-31b）**：改为「具模→内化→开源→长活→结社→大成」五跃迁+定型。方向获认可，但作者自审发现八处硬伤：① v6.1 把初版三个完整版本的工作量伪装成"随行项"，时间盒数学上不成立；② 一条"复测失分于长程状态漂移"的立项证据系推断冒充证据（违反路线图维护规则 §六-4）；③ "N≥30, p<0.05"对 +15pp 量级属统计装饰品（差值标准误≈12.6pp，检测 15pp 需每组 ~166 次）；④ 大量 100%/0 容忍验收必然被定义窄化 gaming；⑤ 铁律 7（6.x 仅新增）与世界模型/代码通道换血本质冲突，未裁决；⑥ 双语言同步（铁律 5）未算账（wazero 无 TS 对等物等）；⑦ 常驻/集群/微调等基建需求被"P0 运营依赖"一笔带过；⑧ 同版建题集同版证明 +15pp 的自判卷问题，预注册无机制。**本稿（08-31c）逐条修复以上八项**。
>
> **弧线主题**：**具模 → 内化 → 开源 → 长活 → 结社 → 大成**
> 从「持续进化的认知 Agent 内核」到「有世界模型、能权重学习、工具自扩张、常驻自主、联结为协作社会的智能个体」。
>
> **一句话叙事**：给内核一个**世界**，给进化一个**身体**，给双手**长新手**的能力，让生命**不睡**，让个体**结成社会**，然后**领证**。
>
> **版本基线**：Go SDK v6.0.x / TypeScript SDK v6.0.x　**日期**：2026-08-31　**状态**：定稿（2026-08-31 维护者评审通过，弧线开工）

## 一、铁律与治理新规

铁律 1–10 全文沿用 [`V6路线图.md`](V6路线图.md) §一。**本弧线追加四条新规**（对应自审 ①③④⑤⑧ 的修复）：

| # | 新规 | 内容 |
|-----|------|------|
| R1 | **容量诚实** | 随行项必须是真·小改动（≤1 周/项）；超过即升格为 S0 预备任务或独立版本，禁止以"随行"伪装完整工作量（自审 ① 教训） |
| R2 | **功效先行** | 一切 A/B 验收须通过功效分析：在声明效应量上功效 ≥80%（配对设计/McNemar/配对 bootstrap），**最小 N≥60/臂**，样本量由设计算出而非拍 30；每个实验附成本估算并经预算门（§八） |
| R3 | **统计措辞禁令** | 质量类指标禁用裸 100%/0 容忍——一律「点估计 + Wilson 95% 下界」写法；**确定性逻辑不变式**（签名校验、CAS 原子性、预算强制）允许 100%/0，因其由代码保证可测试穷尽；对抗类指标用冻结留出集，漏检须全量披露+根因修复复审（自审 ④ 修复） |
| R4 | **题面注册制** | 所有验收题面（基准集、对抗集、holdout）在**开工前**注册进 `docs/evals/`（独立 commit 冻结哈希），≥30% 任务为开发不可见的留出集；验收只认留出集成绩。自发现目标的评判采用注册 rubric + 难度分布披露，防止挑软柿子（自审 ⑧ 修复） |

## 三、v6.1 具模（World Model）——世界从上下文里搬出来

> **本质跃迁**：任务世界成为内核**第一类状态模型**（实体/关系/因果算子状态图）。推理升格为 model-based planning：行动前**预演**、行动后**回溯校验**；上下文窗口从世界的全部来源降格为世界的投影之一。
> **范式对立面**：本框架 v6.0 及主流实践的世界 = 拼接的 ChatMessage 文本。文本会漂移、截断、幻觉因果；模型状态可逐断言证伪。（认知架构领域世界模型早有先例——Soar/ACT-R、Voyager 技能库、Letta 分层记忆等；本版的声明是**通用 Go/TS Agent 框架层面的系统化落地**，不是首创声明。校准点见 v6.3。）
> **立项证据**：① `internal/agent/` 全链路无状态抽象，react_loop 的世界即消息序列（`react_loop.go`）；② plan_checkpoint 恢复的是文本化进度，kill -9 后语义是重放非续知；③ 160 条评估集全为单会话，跨会话状态存活无验收。~~复测扣分集中于长程状态漂移~~（**已删除**：该句系推断，复测报告无此结论——自审 ② 整改）。

### 研究命题（题面 = S0-2 冻结长程集，验收认留出集；R2 功效标准）

| # | 命题 | 量化判据 | 实验预算 |
|---|------|---------|---------|
| 1 | model-based 规划显著优于纯语言规划 | 双臂配对对照（ReAct 基线 vs 世界模型臂）成功率 **+≥15pp**，功效 80%（McNemar 精确功效定 N：不一致率 30% 时 **N=108/臂**，实测以 `SampleSizeMcNemar` 输出为准；下限 ≥60/臂 仅作地板不是判据），p<0.05 | 约 216 次长程任务运行（108×2 臂）× 长程单任务成本，计划书报准；71 题旧估已被功效计算证伪（功效 0.581） |
| 2 | 状态追踪可信 | 回放任务断言准确率点估计 ≥90%、**Wilson 下界 ≥82%**；回溯差异捕获率同口径报告 | 100 条回放人工标注 |
| 3 | 记忆成为模型的状态层 | 基准任务 state→persist→recall 闭环覆盖 100%（确定性覆盖度指标，允许 100）；旧文本路径一致性抽样 ≥99% | — |

### 治理裁决（R 新规配套，开工门 = S0-4 提案通过）

- **6.x 期**：`WithWorldModel()` **opt-in**——铁律 7 不破（现有默认行为零变更）；
- **评价线**：nightly 真实门以 world-model 默认开跑基准——**真实分布证据不受 opt-in 影响**；
- **v7.0**：随主版本重锁翻默认（列破坏性变更 + 迁移指南），届时命题 1 的留出集数字即迁移决策依据。

**工程地板**：状态图内核 + 预检 gate + 回溯差异进失败库 + state-checkpoint 协议——命题 1 不达时的架构层下限（仍是 v6.3 预演与 v6.4 监护的硬依赖）。
**随行（真·小改动）**：状态断言一致性门入 CI 回归；think_budget 消费回溯信号。
**双线索引**：状态图内核/检索/协议 **双线对等**（体量中小）→ §七矩阵 #1。
**验收场景**：一次长程任务四相审计实况（预演→行动→回溯→更新），数字出自 nightly 真实线。
**时间盒**：6-8 周。**前置**：重构风险评审 + S0-4 提案评审通过。

## 四、v6.2 内化（Sleep Learning）——进化从 prompt 走进权重

> **本质跃迁**：轨迹→资产→权重→部署全自动管道：内核全轨迹采集（复用 blackboard/audit/failure 富矿）→ 课程筛选 → 蒸馏数据集导出 → 外接训练（ollama/OpenAI 兼容微调端点，框架零训练依赖、白名单不破）→ 影子评测 → 三段路由替换（影子→灰度→全量，回滚门常驻）。`distiller.go` 从"蒸文本条目"升格"蒸参数技能"。
> **范式对立面**：v6.0 的进化=上下文堆字条——窗口有限、检索有损、跨部署不携带。经验写进身体才是个体的。
> **立项证据**：① `learning/distiller.go` 产物为 KnowledgeItem 文本；② feedback.go 建议只落 prompt/config 层；③ 轨迹资产有采集无出口。

### 研究命题

| # | 命题 | 量化判据 |
|---|------|---------|
| 1 | 蒸馏小模型达窄域旗舰水准 | 结构优势域（工具选择/编码修复/路由决策，域定义注册于 S0-2）：≤8B 蒸馏模型成功率 **≥ 旗舰 ×0.85（95% CI 下界 ≥0.80×）**，配对 N 按 R2 定；**单域达标即版本达标**，其余域滚入 v6.3/v6.4（消除"三域全过"的隐藏风险集中） |
| 2 | 进化跨部署携带 | 权重标准格式落盘，全新环境冷加载性能一致（往返差异 CI 内） |
| 3 | 闭环无人值守 | ≥3 轮采集→蒸馏→影評全程零人工，audit 链完整（确定性流程断言） |

**成本路径**：评测用模型本身进成本账（§八预算）；v6.2 后**部分回归评测可切蒸馏模型跑**，全弧线评测成本随版本递减——这是弧线自我供养的一条暗线。
**治理**：新路由档「蒸馏域」进 model_router/ResilientProvider 契约，灰度+回滚为一等公民；**默认不参与任何既有路由决策**。
**工程地板**：四段管道 + 导出/影子评测格式契约（即使首轮未达 ×0.85，管道是 v6.3 工具彩排与 v6.5 联邦资产的地基）。
**双线索引**：编排/格式/影子评测**双线对等**；训练连接器 **Go-only**（HTTP 端点调用），TS 以工件消费者身份对等 → §七矩阵 #2。
**时间盒**：5-6 周。

## 五、v6.3 开源（Open-Ended Tools）——工具库从预定义变成自己长

> **本质跃迁**：能力缺口自主闭合——缺口检测→生成→**世界模型预演**→WASM 沙箱彩排→对抗测试→签名注册→跨会话复用→劣化退役。v5.4 的 code 层红线开出**受控释放通道**：红线不变式为「**宿主进程代码零写入零加载**」（确定性可穷尽测试），被释放的是沙箱内的工具生成。工具系统第一次是开放集。
> **范式对立面**：MCP 生态与一切现有框架的工具 = 人类预定义清单，能力上限被"别人写了什么"封死。（先例声明同 v6.1：Voyager/自编程 agent 文献在先，本弧线做**框架级**系统化与信任链——非首创声明。）
> **立项证据**：① `ErrImprovementScopeViolation` 把 code 层锁死，缺口只能人肉补；② wazero + ECDSA/cosign + marketplace 协议 + `WASMToolAdapter.AsTool` 四件套齐备而闭环未接；③ tool_learning 只改参数不造新武器。

### 研究命题（题面 = S0-2 缺口任务集冻结留出）

| # | 命题 | 量化判据 |
|---|------|---------|
| 1 | 缺口可自主闭合 | 造工具臂 vs 禁造臂：留出集成功率 **+≥20pp**（R2 功效，N 由设计定，下限 ≥60/臂） |
| 2 | 长出的是资产不是垃圾 | 7 天复用率点估计 ≥60%、Wilson 下界 ≥50%（分母=注册工具数，全量披露） |
| 3 | 安全不变式（确定性门，允许 100%） | 宿主代码零写入零加载：静态+运行时双校验 0 违例；对抗留出集漏检 0，若出现则全量披露+根因复审+补样重跑 |

**治理裁决（开工门）**：S0-4 的 code 通道政策提案**正式生效**——AGENTS.md/护栏/governance 文本从"永久拒绝"修订为"宿主永久拒绝 + 沙箱受控释放"，属**安全承诺变更**，须维护者书面批准 + 红队样本集回归全过，先于功能代码合并。
**外部校准点（弧线中段，铁律 9）**：SOTA 对标矩阵 v2——世界模型/技能库/自编程方向逐项对账，落后项转 v6.4+/v6.5 立项或书面关闭；若校准证明"框架级系统化"已有先行者，弧线叙事按证据修订。
**强验证器族归位**（初版 v6.3 核心任务在此消化）：CodeExecVerifier（彩排复用）、EnsembleJudgeVerifier（数据集清洗+退役判定）、假接受率标定（≥300 样本，Wilson 口径）——**作为本版核心任务的内部构件交付**，不再独立成版。
**工程地板**：工具六段生命周期框架 + 缺口审计报表 + 签名信任链。
**双线索引**：沙箱执行 **Go-only**（wazero 无 TS 等价物）；TS 侧**协议对等**（签名/工具包格式/注册客户端），TS 沙箱执行委托 gateway 服务节点（gateway 模块已在线）→ §七矩阵 #3。
**时间盒**：5-6 周。

## 六、v6.4 长活（Long-Live）——存在形态从会话变成生命

> **本质跃迁**：请求驱动升格为事件驱动常驻生命：自唤醒（定时/环境/webhook/文件监视）、目标自主生成与生命周期管理、闲时自调度（v6.2 学习、v6.3 造工具、v6.1 模型整理挂进 idle 环）、崩溃自愈重启、对已负责世界的监护。
> **范式对立面**：框架至今形态 `Run(ctx, task)` 返回即死亡；autonomy 原语全为"一次调用内的半活"设计。
> **立项证据**：① 评估集全为单会话（长程题面已于 S0-2 补）；② Goal 生命周期依附会话；③ v6.1–v6.3 三构件各自需要被调用的宿主——弧线至此必须有生命体承载。

### 研究命题

| # | 命题 | 量化判据 |
|---|------|---------|
| 1 | 无人值守长存 | 长活 nightly 实例：**2026-09-01 维护者裁定压缩口径**——真机常驻 **≥72h** + **加速崩溃注入 ≥75 次**，自愈成功率点估计 ≥99%、Wilson 下界 ≥95%（与原判据同一统计式：全自愈 n=75 → 下界 95.13%；原 ≥14 天的日历长尾由小时级资源遥测披露 + 伪时钟 14 天确定性模拟覆盖，残余风险在 soak 报告书面披露）；人工介入次数全量披露（介入=告警平台的人工动作，含 0 也要列每事件审计）；预算护栏合规为**确定性不变式**（超额 0，代码强制允许 0） |
| 2 | 主动创造价值 | 自发现目标闭环成功率 ≥70%：**评判走 R4 注册 rubric**——目标产出即过难度分级（校准 judge + 分布披露），禁止自评自证；主动臂 vs 被动应答臂在冻结题面 **+≥15pp**（R2 功效） |
| 3 | 闲时进化可证 | idle 产出（学习/工具增量）对次日性能 A/B 正贡献 **≥+3pp**（R2 功效，CI 报告） |

> **裁定记录（2026-09-01，维护者）**：命题 1 的「连续 ≥14 天」压缩为「≥72h 真机 + ≥75 次加速崩溃注入」。理由：①门的统计核心（自愈点估计 ≥99%、Wilson 下界 ≥95%）按试验次数计、与日历无关——n=75 全自愈即拿满原口径（下界 95.13%），且 ≥75 为原判据 ≥20 次的超集；②日历时长唯一独占的证据是慢泄漏与长尾环境事件，该风险转由小时级资源遥测（heap/goroutine/FD/状态目录体积，斜率全量披露）与既有伪时钟 14 天确定性模拟覆盖；③压缩实测由 `internal/agent/live/soak.go`（机制+判定）与 `bench/soak-v64`（真实时钟驱动器）承载，遥测与判定全量落盘 `bench/results/v64-soak/`。残余风险（>72h 尺度的慢泄漏、真实 LLM 代谢下的长尾）不宣称闭合，在 soak 报告 notes 中书面披露。
**增补（2026-09-03，维护者授权「决定就行」）**：`last` 记录实证本机存在每日关机/重启周期（09-02 18:24 关机 / 21:19 开机 / 09-03 09:30 重启），「连续 72h」在该环境不可达——口径修订为**累计在线 ≥72h**：soak harness 状态持久化（`soak-state.json`，注入/遥测后原子落盘）跨重启续计注入与时长，报告全量披露重启次数与每段在线区间（segments 字段）；各在线段均为真实连续运行，机器断电属环境属性不属被测属性。续计版启用前的历史在线证据（5 段合计 24.67h、30 注入 30 自愈 0 失败）以 `soak-report.interrupted-*.json` 归档披露，不计入累计窗口（该窗口自续计版启用起算，只可能保守低估不虚报）。

**治理裁决**：常驻运行时 = **新部署形态**，非默认（`ap live` 显式启动），不改任何既有会话语义——铁律 7 天然无冲突（写明，区别于 v6.1 的翻转裁决）。
**工程地板**：事件总线接线（复用 `internal/events`）、自唤醒协议、idle 调度器、监护-自愈守护、长活 harness。
**双线索引**：常驻循环/idle 调度**双线对等**（TS=Node/worker 长循环形态）；托管宿主共用 → §七矩阵 #4。
**验收场景**：14 天长活日志故事线（夜里学习→晨间发现环境变化→自主处理→一次崩溃自愈），附 R4 审计导出。
**时间盒**：6-7 周。**前置**：生命周期重构评审 + 长活宿主就位（§六清单 B2）。

## 七、v6.5 结社（Society）——智能从个体属性变成集体涌现

> **本质跃迁**：常驻个体联结为社会——跨节点组织（Blackboard × cluster 总线 × etcd 租约）+ **联邦进化**（流通蒸馏 adapter、签名工具、世界模型断言摘要——流通学习成果而非原始数据）+ 社会信任层（贡献声誉复用 OrgRouter 数据驱动机制，投毒对抗）。v5.5 证明了单进程 8 体的**分工涌现**；本版证明**学习成果的集体涌现**：一个个体学会，全社群变强。
> **立项证据**：① `organization.go` Blackboard 为进程内结构（实证规模止于单机 8）；② cluster/grpc_bus/etcd 全套传输共识件与组织**零接线**；③ A2A interop 在线但零第三方对账、无资产流通语义。

### 研究命题

| # | 命题 | 量化判据 |
|---|------|---------|
| 1 | 分布式社会不降质 | 3 节点 × ≥16 成员 vs 单机同规模：成功率下降点估计 **≤2pp、95% CI 上界 ≤5pp**；分区混沌脏认领冲突 0（CAS 确定性不变式） |
| 2 | 结社产生个体做不到的智能 | 联邦臂 vs 隔离臂：对**全节点未经历**的留出任务域 zero-shot **+≥20pp**（R2 功效）——涌现的可证伪定义 |
| 3 | 信任层可对抗 | 签名伪造/篡改：**确定性校验 0 漏**（允许 100）；声誉刷分与坏贡献：留出集拦截率 ≥95%（Wilson 口径），误拦率全量披露 |
| 4 | 对外开放 | ≥1 个外部框架（langgraph/autogen）互通基准 N≥20 **全通**（单例失败=修根因重跑全集，非放宽门槛——这是发布语义，非统计宣称）；租户隔离对抗 0 泄漏（确定性策略门） |

**工程地板**：跨节点 Blackboard 协议、联邦资产三形态（skill-card/tool-package/model-adapter）、声誉信任模型、分区容错租约。
**双线索引**：黑板/租约/联邦协议**双线对等**（TS 以组织客户端+资产消费者身份）；节点运行时随各 SDK → §七矩阵 #5。
**验收场景**：三节点各自在不同域"长大"→合并→统一留出评测展示"一个节点踩坑、另一节点零成本避开"+ 一次投毒绞杀实录；顺带正式关闭 v6.0 残余 #4。
**时间盒**：7-8 周。**前置**：3 节点集群就位（§六清单 B3）。

## 十、实验成本与功效标准（R2 细则）

- 每个实验计划书四件套：假设 / 效应量与功效计算 / 分析计划（含多重比较校正）/ token 成本估算。
- 功效基准：80% 功效下检测 +15pp 约需每组 100–170 次（未配对）；**配对设计（同题双臂）显著降本**，鼓励。
- 版本验收实验为「里程碑级」全量跑；版本开发期用「探索级」小样本（明示不可用于验收）。
- 蒸馏模型上线后（v6.2+），与旗舰对照无关的回归评测可切低价臂——**本弧线的量化野心由弧线的学习产物供养**，此为本弧线经济学上的自洽性声明。
