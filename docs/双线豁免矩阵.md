# 双线豁免矩阵（S0-5）

> **定位**：V7 弧线铁律 5（双语言同步）的执行台账。核心能力变更 Go/TS 对等落地；无法即时对等的条目在本表登记**书面豁免**，杜绝「沉默的不一致」。
> **规则**：
> 1. 每个弧线新能力立项时必须在本表登记一行：双线状态 = `对等` / `Go-only` / `TS-only` / `协议对等+运行时豁免`；
> 2. 豁免必须附**理由**与**升格条件**（何时、以何种形态补齐对侧）；
> 3. 本表进 CI 审查（`scripts/dual-line-matrix-check.mjs`，校验表内引用的模块路径真实存在）；
> 4. TS 侧以**协议/格式消费者**身份参与时记 `协议对等`——共享数据契约（签名格式、资产包、API wire format）必须双线一致，豁免仅针对**执行运行时**。
