## 主题：开发者体验重构

v0.8.0 聚焦「从零到第一个 Agent」的开发者体验。新增 3 个公共 API + 1 个 testutil 包，更新 9 个示例文档，把 50+ 行的样板代码压到 3 行。

## 新增公共 API

### `ap.NewAgent()` 简化入口

**问题**：`ap.NewReActAgent(ap.ReActConfig{...})` 有 14 个 Deprecated 字段污染 IDE 视野。

**方案**：

```go
// 旧（14 个废弃字段可见）
agent := ap.NewReActAgent(ap.ReActConfig{
    Name: "bot", SystemPrompt: "...", Model: provider, MaxTurns: 10,
    // Toolkit/Memory/RAG/Hooks/Tracer... 14 个 Deprecated 字段
})

// 新（只暴露核心参数，能力用链式 API）
agent := ap.NewAgent("bot", "...", provider, ap.WithMaxTurns(10)).
    WithMemory(mem).WithRAG(rag).WithHooks(hooks)
```

**新增项**：
- `ap.NewAgent(name, systemPrompt, model string, opts ...AgentOption) *CapabilityAgent`
- `ap.AgentOption` 类型别名
- `ap.WithMaxTurns(n int)` — ReAct 最大迭代次数
- `ap.WithTemperature(t float64)` — LLM 温度
- `ap.WithSessionID(id string)` — 跨轮记忆关联

**向后兼容**：`ap.NewReActAgent(ap.ReActConfig{...})` 仍可用，无破坏性变更。

---

### `agent.WithRAGMemory(mem, emb)` 一步 RAG

**问题**：启用 RAG 需要 6 步手动组装（NewEmbeddingAdapter → NewRAGStore → NewRAGProviderAdapter → RAGConfig → WithRAG）。

**方案**：

```go
// 旧（6 步）
adapter := ap.NewEmbeddingAdapter(provider, 1536)
ragStore := ap.NewRAGStore(memory, adapter)
ragProvider := ap.NewRAGProviderAdapter(ragStore)
agent := ap.NewReActAgent(ap.ReActConfig{
    Model: provider,
    RAG: &ap.RAGConfig{Provider: ragProvider, Mode: ap.RAGModeAuto, TopK: 5},
})

// 新（2 步）
agent := ap.NewAgent("bot", "...", provider).
    WithMemory(memory).
    WithRAGMemory(memory, provider)  // 自动完成所有适配
```

**实现细节**：内部用私有 `ragStoreAdapter` 将 `*memory.RAGStore` 适配为 `agent.RAGProvider`，对用户完全透明。默认参数：`Mode=RAGModeAuto`、`TopK=5`、`MinScore=0.3`。

### `testutil` 包：测试辅助工具

**问题**：每个示例和测试都要手写 40 行 `MockLLM` 实现 `llm.Provider` 接口。

**方案**：新增 `agentprimordia/testutil` 包，提供 `MockProvider` + `NewTestAgent()` 快捷构造器。

```go
import "github.com/Gleamseekers/AgentPrimordia/agentprimordia/testutil"

func TestMyAgent(t *testing.T) {
    // 预设响应序列
    mock := testutil.NewMockProvider(
        "第一次响应",
        "第二次响应",
    )
    mock.WithToolCalls(llm.FunctionCall{...})  // 工具调用预设
    mock.WithDelay(100 * time.Millisecond)    // 延迟注入
    mock.WithError(errors.New("simulated"))    // 错误注入

    if mock.CallCount() > 0 {
        // 断言
    }
}
```

**新增项**：
- `testutil.MockProvider` — 实现 `llm.Provider` + `llm.Embedder`
- `testutil.NewMockProvider(responses ...string) *MockProvider`
- `testutil.NewTestAgent(cfg TestAgentConfig) *CapabilityAgent` — 一行创建可测 Agent
- `testutil.TestAgentConfig` — 快捷构造器配置

**向后兼容**：`cmd/example/demo/DemoLLM` 仍可作为类型别名引用（`type DemoLLM = testutil.MockProvider`）。

## 内部 API 变化（不破坏公共 API）

### `pkg/options.go` 重命名

为避免与 `ap.NewAgent()` 的函数式选项重名，旧的 options 重命名：

| 旧 | 新 |
|----|----|
| `WithMaxTurns` (在 `pkg/options.go`) | `WithMaxIterations` |
| `WithTemperature` (在 `pkg/options.go`) | `WithTemp` |

> 这些旧 API 实际无人使用（之前是死代码），新 API 在 `ap.WithMaxTurns` / `ap.WithTemperature`（更准确，符合调用约定）。

## 升级建议

新项目直接用新 API：

```go
import (
    "github.com/Gleamseekers/AgentPrimordia/agentprimordia/pkg"
    ap "github.com/Gleamseekers/AgentPrimordia/agentprimordia/pkg"
    "github.com/Gleamseekers/AgentPrimordia/agentprimordia/testutil"
)

mock := testutil.NewMockProvider("hello")
agent := ap.NewAgent("my-bot", "you are helpful", mock, ap.WithMaxTurns(10))
resp, _ := agent.Run(ctx, ap.UserMessage("hi"))
```

老项目无需修改。新 API 与旧 API 完全并存。建议在新代码中用 `ap.NewAgent()`，旧代码可逐步迁移。
