# AgentPrimordia v7.5.0 — 评估修复战役 + 首次可发布模块路径

> **发布日期**: 2026-09-28
> **影响范围**: v7.4 接线批次（trunk 未发）+ 2026-09-28 深度评估修复战役（4 P0 / 12 P1 / 全部 P2）+ 模块路径迁移 + 诚实遗留项清零
> **向后兼容**: ⚠️ **模块路径变更**（旧路径 `agentprimordia` 从未可经 GOPROXY 解析、无下游模块消费者，故无实际兼容影响；源码 clone 用户与本地 replace 用户需更新 import 路径，见下）

## 摘要

本版是一次**安全与质量战役**的交付：对全仓（302K 行 Go）进行深度评估，实证复现 4 个 P0（默认 Shell 工具 7 条攻击链 RCE、jsonutil 并发请求体覆写 99.5%、Anthropic 公开 API panic、167 个测试被禁用）与 12 项 P1，全部以 TDD 修复并以回归测试固化；覆盖率 78.8% → **81.1%**；测试文件 622 → **659**。同时完成五项工作区模块向 `github.com/Gleamseekers/AgentPrimordia/agentprimordia` 命名空间的迁移——**框架自此可经 GOPROXY 分发**。

## 安全修复（P0，评估实证）

| 项 | 说明 |
|----|------|
| **Shell 工具白名单绕过（RCE）** | 默认白名单移除 env/printenv/python*/node/go/find/git 等可派生进程/解释代码条目；args 逐元素元字符校验；绝对路径 token 过 allowedWorkdirs/Sandbox；DefaultToolkit shell 默认禁锢 RootDir；黑名单 token 化匹配；scope 提取完整递归 + fail-closed；敏感模式大小写不敏感。7 条攻击链回归测试固防 |
| **jsonutil.Marshal 并发覆写** | pooled buffer 归还后返回其切片 → 并发下请求体被整体替换（实测 2000 次 99.5% 损坏 + 跨会话数据泄漏）。修复为归还前拷贝 |
| **Anthropic 结构化输出 panic** | `ResponseFormat{Type: json_object}`（无 schema）nil deref → 通用兜底 tool |
| **167 个测试被 `//go:build ignore` 禁用** | 12 个文件去标签并修复腐烂（符号冲突/类型漂移/API 迁移）；覆盖率恢复可信 |

## 质量修复（P1/P2，摘要）

- **llm ×7**：Stats 原子读（-race 实证）；ctx 取消不再误触发熔断；transport 单例；流式长流不再被 Client.Timeout 掐断；缓存键切完整请求指纹（消除跨上下文假命中）；TTL goroutine 可关闭；LSH 索引清理
- **tools ×8**：RegisteringCreator INV-0 门控（宿主零执行 agent 生成代码）；插件安装器穿越净化 + 先验后写 + 大小上限；MCP 常量时间认证 + 子包 WithAPIKey；stdio 64KB 挂起；子进程 env 白名单（宿主密钥不泄露）；SSRF 残留段补全；web/http_client 连接池共享；data_tools rootDir jail
- **agent ×6**：trace span 全部闭合（8 路径回归）；锁纪律修正；HITL 并行不再挂死；摘要 goroutine 有界池；runLoop 134 行/cc23 → 71 行/cc11；流式 tool_calls 单请求化（费用/延迟减半）
- **覆盖率补课**：federation 33%→98%、config 64%→98%、a2a 66%→86%；补课过程实测修复 5 个生产缺陷（a2a interop_server 数据竞争、federation 重放刷声誉等）
- **诚实遗留清零**：FalsePositives 误拦口径接线；config FlagSet 注入；intelligence pkg 导出（ecosystem internal 依赖清零）

## 模块路径迁移（ Changed ）

五个工作区模块迁至 `github.com/Gleamseekers/AgentPrimordia/agentprimordia` 命名空间：

| 模块 | 新路径 |
|------|--------|
| 主模块 | `github.com/Gleamseekers/AgentPrimordia/agentprimordia` |
| pgvector / operator / gateway | `github.com/Gleamseekers/AgentPrimordia/{pgvector,operator,gateway}` |
| wasm 沙箱 | `github.com/Gleamseekers/AgentPrimordia/agentprimordia/wasm` |

**迁移影响**：旧路径首段无点号，GOPROXY 无法解析（`go install` 一直不可用）——模块此前不存在下游消费者，无兼容契约可破坏。源码构建用户的 import 路径需更新；本地 replace 消费方式见 `agentprimordia/docs/版本规范.md`。
