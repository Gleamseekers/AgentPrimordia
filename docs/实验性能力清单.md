## 三、待接线项：成本与前置风险

> 成本为工程量估计（人日），**标注了审计中发现的隐藏前置条件**——不要按"改一行"预期排期。

1. **工具学习器自动装配**（原估 S/0.5d，实测有阻塞）
   - 阻塞：`tool_learning.MemoryStore` 要求 `Add(*tool_learning.Episode)` + `Query(sessionID, metadata)`，
     与 `agent.MemoryStore`（`Add(*memory.Episode)` + `UpdateSummary`）**签名不兼容**，且后者无 Query 能力。
   - 需要：新增可选接口（如 `EpisodeQuerier`）或适配器，把 `memory.Episode ↔ tool_learning.Episode` 互转。
   - 实际成本：**M（1–1.5d）**，含 TDD。

2. **全链路关联存储默认构造**（原估 S/0.5–1d）
   - 阻塞：`CorrelationStore` 的记录以 `map` 保存，需要先确定 retention / 上限，否则长驻进程内存无界。
   - 实际成本：**M（1d）**，需一并补 retention 测试。

3. **OTel 端到端接线**（S–M，1d）
   - 在 `cmd/ap` 按 env 构造 `TelemetryProvider` 并 `ap.WithTelemetry(...)`，或明确放弃并删 `pkg/otel.go` 的 Experimental 子集 + `internal/otel/`。

4. **Studio 接真实引擎**（M，3–5d）：`cmd/studio/main.go` 构造 chaos/cluster/memory.SelfModel、autonomy/skills/realtime 并传 `With*`；适配器已写好，属纯装配。

5. **模板注册表持久化 + 远程协议**（M，1–2d）：接 `internal/persist`，复用 `internal/marketplace` 的 HTTPS/验签。

6. **技能库持久化 + 入循环**（M，2–3d）：Store 接 `internal/persist`；Matcher 挂入 ReAct 工具选择。

7. **自治 CLI 真实化**（M–L，2–4d）：替换 `cmd/ap/autonomy.go` 打印为 StepExecutor + CheckpointStore 装配。
